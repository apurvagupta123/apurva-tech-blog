## Blog Post Template for Daily Creation

### Metadata
```
Title: [Generated from trending topic]
Date: [Today's date]
Category: [AI/Robotics/Infrastructure/etc]
Author: Claude AI
Tags: [Comma-separated tags]
Featured Image: [Banner filename]
```

### Structure
1. **Opening Hook** (50-75 words)
   - Start with relatable scenario
   - Create curiosity/interest

2. **Setup Section** (100-150 words)
   - Explain the context
   - Why this matters now

3. **Deep Dive** (250-400 words)
   - Multiple sections/stories
   - Analogies and examples
   - Data and metrics woven in

4. **Implications** (75-150 words)
   - What it means for readers
   - Real-world impact
   - Future outlook

5. **Closing** (one paragraph)
   - Call to wonder/reflection
   - Memorable takeaway

### Quality Checklist
- [ ] Fact-checked (all claims verified)
- [ ] Grammar & spelling reviewed
- [ ] Story-driven narrative
- [ ] 500-1000 words
- [ ] No jargon without explanation
- [ ] Real-world examples included
- [ ] Professional banner created
- [ ] Optimized for SEO
- [ ] Sources cited
